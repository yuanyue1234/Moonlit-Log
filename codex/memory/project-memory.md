# 手帐小程序项目记忆

## 当前项目状态
- 微信小程序，核心页面包括首页、编辑器、贴纸库、素材提取、模板选择。
- 编辑器使用 Canvas 2D 自绘，元素包含文字、图片、贴纸、矩形/装饰、主题固定元素。
- 数据存储在本地 storage：`journal_books`、`journal_pages`、`sticker_assets`。
- 手帐体系已调整为：每本手账必须有第一页封面，封面包含名称、标签、主题风格；普通页按主题生成不同背景、纸面材质和固定装饰元素。

## 本轮关键修复
- 修复编辑器编译失败后的遗留风险：全量 JS 语法检查通过。
- 修复封面保护链路：`bookPages` 现在包含 `role`，封面页不会被删除或套用模板。
- 修复提取页“放入手帐”只跳转不放入素材的问题：现在会带 `stickerId` 进入编辑器，并自动放置一次。
- 修复矩形文字入口体验：矩形更多菜单根据状态显示“添加文字/编辑文字”，并防止锁定元素被文字面板修改。
- 字体加载改为多源兜底：优先使用 LXGW Yozai GitHub release，失败后尝试备用源，全部失败则降级系统字体且不阻断启动。
- 贴纸后处理仍采用 alpha mask 方向：白边、纸贴、阴影贴合透明主体轮廓，避免矩形底。

## 仍需真实设备/开发者工具验证
