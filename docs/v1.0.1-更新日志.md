## 核心能力

### 手帐编辑器
- Canvas 2D 全自绘引擎，支持拖拽 / 缩放 / 旋转 / 复制 / 删除 / 置顶置底 / 锁定
- 撤销重做最多 50 步，每页独立历史，500ms 防抖自动保存
- 6rpx 对齐参考线吸附，图层按 zIndex 渲染

### 元素体系
- **图片**：添加 / 替换 / 裁剪 / 白边纸贴阴影特效
- **文字**：字体 / 大小 / 颜色 / 对齐，支持手写体
- **形状**：矩形 / 圆形 / 椭圆 / 圆角矩形 / 心形 / 星形，矩形支持填充图片拖拽定位
- **装饰**：线条 / 点 / 背景纹路（grain / canvas / kraft / linen / watercolor）
- **当下组件**：时间 / 日期 / 地点（手动输入）/ 节气，一键插入

### 主题与模板
- **8 种主题**：奶油风 / 复古拼贴 / 韩系清透 / 日系杂志 / 少女粉 / 蓝白海盐 / 咖啡手帐 / 胶片旅行
- **8 种模板**：今日手帐 / 一周碎片 / 照片墙 / 旅行记忆 / 美食日记 / 学习笔记 / 心情日记 / 清单打卡

### 素材管理
- 贴纸库支持分组、搜索、收藏、批量上传、快速编辑删除
- AI 智能标签自动识别素材风格

### 导出
- PDF 导出（含进度条，自动清理存储空间）
- 单页图片导出

## 本次更新（v1.0.1）

### 🛠 修复

- **修复启动崩溃**：移除 `lazyCodeLoading` 配置，解决与基础库 3.16.1 的页面注册冲突
- **修复 Babel 报错**：关闭非必要的 ES6 转译，`@babel/runtime` 模块在微信运行时不存在
- **修复选中工具栏重叠**：工具栏位置从固定顶部改为浮动工具栏正下方，水平居中不再遮挡

### ✨ 优化

- **选中工具栏**：固定水平居中，支持拖动微调位置，切换选中元素时偏移共享，退出页面自动复位
- **模板全面升级**：8 个模板从基础布局重写为多层精致设计，每种模板有独特视觉风格
- **一键清空页面**：仅「全部」分组显示，尺寸与模板卡片统一

### 🔒 隐私

- **移除位置权限**：`wx.chooseLocation` 改为手动输入地点，`app.json` 零敏感权限声明，降低审核风险
