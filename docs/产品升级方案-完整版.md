# 手帐小程序产品升级方案（完整版）

原则：不照搬可画的品牌和图标，但复刻它成熟的编辑体验结构。

## 总目标
- 首页：手帐本管理台
- 编辑器：可画式画布编辑器，视觉是纸质手帐
- 贴纸库：只管理真实贴纸素材
- 提取页：去背景素材只生成一份
- 阅读/预览模式：3D 滑动翻页
- 编辑模式：不触发翻页

## 第一阶段：修基础体验
1. 修重复素材 bug
2. 移除 emoji 素材
3. 替换线条图标
4. 修底部安全区
5. 贴纸全屏预览

## 第二阶段：编辑器升级
1. 重构顶部工具栏
2. 增加选中对象菜单
3. 增加图层/对齐/复制/删除
4. 增加字体选择
5. 增加纸张样式

## 第三阶段：手帐感
1. 首页继续编辑
2. 纸质画布视觉
3. 非编辑模式 3D 翻页
4. 模板真实缩略图

## 最小验收版本
用户能提取一个贴纸 -> 在贴纸库全屏查看标签 -> 放入手帐页 -> 选中后复制/删除/置顶 -> 添加文字并切换字体 -> 进入预览模式 3D 翻页
