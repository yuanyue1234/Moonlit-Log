# 关于作者

## 作者身份

「我的手帐」的作者是小晴。

小晴是一位关注审美、记录感和创作体验的产品创作者。她希望把现实中的小卡、票根、周边、照片和日常碎片，整理成具有纸质质感的电子手帐，让收藏不只是堆在相册里，而是可以被重新排版、讲述和保存。

## 创作初衷

这个项目的核心不是做一个普通图片编辑器，而是做一个更贴近「手帐」的收藏整理工具。它把手帐本、封面、主题风格、纸面材质、模板、素材库和导出串成一条完整流程：

1. 保存收藏物。
2. 管理素材库。
3. 选择手帐本和主题。
4. 在纸质画布上排版。
5. 预览和导出。

小晴希望用户打开小程序后，可以快速把某个值得纪念的东西做成一页手帐，而不是从空白画布里迷路。

## 审美方向

作者偏好的产品气质是「精致、克制、有纸感」。界面层面借鉴深色工程化设计，使用近黑背景、电绿色强调色、细线边框和清晰的信息层级；手帐内容层面则强调温暖、纸纹、胶片、拼贴、手写和收藏物本身。

当前项目包含多种手帐主题，包括奶油风、复古拼贴、韩系清透、日系杂志、少女粉、蓝白海盐、咖啡手帐、胶片旅行等。每种主题都服务于不同记录场景，而不是只换一组颜色。

## 产品原则

- 真实素材优先：素材库只管理用户上传或拍摄的真实收藏物。
- 手帐感优先：画布、纹理、模板和装饰都应服务于纸质记录感。
- 隐私优先：当前公开口径下，用户内容默认保存在本地，不上传云端。
- 低打扰：不强制登录，不使用埋点统计，不默认请求敏感位置权限。
- 不误删：封面页、模板覆盖、页面删除等高风险操作需要保护或确认。

## 作者希望解决的问题

很多用户会收藏大量图片、票根、小卡和周边，但这些内容容易散落在相册或聊天记录里。「我的手帐」希望提供一个更有仪式感的整理方式：把收藏物变成一页页可编辑、可预览、可导出的手帐。

对作者来说，这个项目的价值在于让回忆有结构，让素材有去处，也让用户可以用很短的路径完成一次好看的记录。

## 当前版本重点

当前版本聚焦微信小程序原生能力和本地编辑体验。核心页面包括首页、编辑器、素材库、保存收藏物和模板选择。编辑器基于 Canvas 2D 自绘，支持多页面管理、主题封面、模板、元素编辑、纸面材质、贴纸后处理和导出。

后续如果对接 AI QA，作者相关回答应保持温和、清晰、克制，强调「收藏物手帐」「本地隐私」「纸质质感」「快速做成一页手帐」这几个关键词。
