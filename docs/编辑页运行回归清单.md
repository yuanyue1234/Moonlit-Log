# 编辑页运行回归清单

更新时间：2026-06-17

这份清单用于微信开发者工具 GUI、预览码或真机回归。静态脚本已经覆盖结构和资源，但以下项目必须在运行时确认。

## 1. 编辑页视觉统一
- 从首页进入任意手账本，确认编辑页背景为暖纸色，不出现旧暗色背景。
- 顶部栏、画布外壳、浮动工具栏、选中工具栏、底部弹层、选中更多菜单、颜色选择器、形状填图弹窗保持同一套暖纸色线条风。
- 底栏 TabBar 图标可见：手账为书本线条，素材库为贴纸线条；未选中暖棕，选中玫瑰粉。
- 编辑页内 SVG 图标均可见，不出现空白图标。
- 移动/点击工具栏按钮时，文字和图标 hover/触摸态足够明确，不出现刺眼或脏色。
- 自定义颜色入口的 `+` 图标居中且比旧版更清楚，白边不显得突兀。

## 2. 页码条和页面管理
- 编辑模式：底部页码跳转条隐藏。
- 预览模式：底部页码跳转条显示，可点击上一页、下一页和页码圆点跳转。
- 编辑模式右上角更多菜单可添加下一页。
- 非封面页且页数大于 1 时，右上角更多菜单可删除当前页。
- 第一页/封面页不出现可点击的删除页入口，页面管理按钮位置不再跳动。

## 3. 图片、贴纸和页面删除
- 在第 2 页添加一张图片，确认素材库“照片”出现对应贴纸。
- 删除第 2 页后回到素材库，确认刚才随页面生成的照片贴纸不再残留。
- 如果同一图片仍被其他页面使用，删除某一页后确认其他页面图片不丢失。
- 在封面页删除封面图片，返回首页后再次点击该手账本，确认旧封面图片不会重现或位置漂移。
- 清空页面后，确认页面独有的照片/形状照片/手绘贴纸不会残留在素材库。

## 4. 图片裁切
- 选中普通图片，点击选中工具栏“更多”，确认出现“裁切”。
- 点击“裁切”，确认能打开小程序原生裁切界面。
- 完成裁切后，当前图片被裁切后的图片替换。
- 裁切后的图片作为新的唯一贴纸进入素材库，旧图对应的唯一贴纸被回收。
- 锁定图片后再次点击裁切，确认提示先解锁，不会修改图片。

## 5. 全屏手绘
- 点击“手绘”进入全屏工作台，确认不是底部小面板。
- 顶部包含关闭、标题、撤销、重做、完成；撤销/重做在完成旁边。
- 底部工具栏顺序为：选择贴纸、画笔颜色、画笔粗细、工具。
- 点击画笔颜色弹出颜色面板；点击画笔粗细弹出粗细面板。
- 点击“工具”在画笔和橡皮之间切换，再次点击能切回画笔。
- 在画布上半部分和下半部分都能连续绘制，不出现视觉区域大但下半区无法手绘。
- 点击撤销/重做，笔画历史正确变化。
- 选择贴纸后能在手绘画布中盖章。
- 点击完成后，手绘内容保存为“手绘”贴纸并自动放入当前手账页。
