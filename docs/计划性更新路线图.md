# 我的手帐计划性更新路线图

日期：2026-06-16
版本基线：v1.0.1 正式版
当前定位：微信原生小程序，本地优先的可视化手帐编辑器

## 调研结论

这次调研把同类产品分成四类：视觉手帐、私密日记、引导式记录、网页/小程序编辑器。

### 1. 视觉手帐类
- 时光手帐强调海量贴纸、胶带、背景分类，自定义素材、变色贴纸、音乐/动态手帐、智能图片手帐、一键排版、私密手帐本、社区和教程。
- 微手帐强调模板、原创贴纸包、GIF 动态贴纸、咕卡、素材导入、智能抠图、手帐本集合、关键词搜索、一键分享、好友一起做手帐、密码、备份、通知提醒。
- Goodnotes、Zinnia 这类数字计划本强调 planner、贴纸、纸胶带、模板、可编辑贴纸、素材集合和跨页面复用。
- Canva 可画强调在线模板化设计，用户从模板进入创作，降低空白页压力。

对我的手帐的启发：继续强化“贴、排、装饰、复用”，但不要变成素材商店优先。先把用户从“今天想记录”带到“很快做出一页好看的手帐”。

### 2. 私密日记类
- Day One 强调多媒体记录、标签搜索、端到端加密、自动备份、导出和多端体验。
- Journey 强调跨平台、照片/视频/音频记录、心情追踪、共享日记和加密。
- Diarium 强调照片、地点、标签、提醒、私有云同步、无广告/无订阅口径。
- Penzu 强调密码锁、加密、标签、搜索、离线写作、封面和主题。

对我的手帐的启发：隐私是核心卖点。v1.0.1 已移除位置权限，后续可以把“本地保存、可导出、可备份、可加密”做成明确承诺。

### 3. 引导式记录类
- Grid Diary/格志日记强调格子化提示、问题库、日/周/月/年复盘、习惯、目标、标签和分类。
- Apple Journal 强调用设备内智能生成记录建议、反思提示、照片/视频/地点/音频，并通过通知培养习惯。

对我的手帐的启发：不要只给空白画布。需要给“今天写什么”的提示卡和“这周/月发生了什么”的回看入口。

### 4. 小程序/网页编辑器类
- LemonJournal 微信小程序 demo 将 sticker、image、text 等组件保存为 JSON，恢复编辑时解析 JSON 重新渲染。
- wxml-to-canvas 这类小程序生态组件说明，小程序内生成分享图/导出图可以走静态模板到 Canvas 的方向。

对我的手帐的启发：当前项目已经是 Canvas 2D 自绘，后续重点不是换技术，而是把页面 JSON、素材 JSON、模板 JSON 做成更稳的备份、迁移和模板扩展基础。

## 产品原则

- 本地优先：默认不上传用户内容，不请求不必要权限。
- 先完成一页：任何新增能力都要帮助用户更快完成一页手帐。
- 手帐感优先：模板、贴纸、纸面、文字、留白、层次比复杂功能更重要。
- 计划性更新：每次只推进一个核心体验，不把编辑器一次性堆复杂。
- 可回退：新增 AI、云同步、社区前必须保持本地备份/导出能力。

## 推荐版本节奏

### v1.0.2 - 发布稳固与回归
目标：让 v1.0.1 更像可长期迭代的正式底座。

- 微信开发者工具完整回归：首页、建手帐、封面、编辑器、素材库、提取页、导出。
- 增加手动回归清单文档，避免每次更新忘测关键链路。
- 增加本地 JSON 备份导出/导入草案，优先保护用户数据。
- 检查产品名称统一：我的手帐/月照雪/备案说明/页面标题。
- 梳理 `editor.js` 拆分计划，不立即大拆，但先标出模块边界。

### v1.1 - 更靠近“每日手帐”
目标：让用户每天打开都有明确入口。

- 今日入口：从首页直接创建“今天的一页”。
- 心情/天气/地点手动标签：延续无位置权限策略，地点默认手输。
- 提示卡：今天最想记住的一件事、今天的小确幸、今天的颜色、今天的照片。
- 月历视图：按日期查看已有页面和空白日。
- 最近使用模板/最近使用素材：减少重复寻找。

### v1.2 - 素材与拼贴效率
目标：把“贴素材”做顺手。

- 素材包：按主题保存一组贴纸/胶带/背景。
- 收藏模板：把当前页面保存为自定义模板。
- 批量导入素材后的自动分组和标签确认。
- 可选智能抠图回归方案：先作为可开关能力，不影响默认隐私口径。
- 贴纸细节增强：描边强度、阴影方向、纸贴纹理、透明边缘预览。

### v1.3 - 回看、复盘与计划
目标：让手帐不只是做图，而是生活记录系统。

- 标签搜索：按心情、主题、人物、地点、素材类型查找。
- 周/月复盘页：自动汇总本周页面、心情、打卡、照片。
- 打卡组件：习惯、饮水、阅读、运动、学习等轻量勾选。
- 倒计时/纪念日组件。
- 那年今日/过去这一周：从本地记录中回看。

### v1.4 - 分享与导出
目标：让完成的一页更容易被保存和分享。

- 单页高清图导出优化。
- 多页 PDF 导出稳定性和进度提示优化。
- 分享海报模板：带标题、日期、作者署名，可选择是否显示水印。
- 打印成册前置准备：封面、目录、页码、导出规格。

### v1.5 - 可选云与协作
目标：只在本地体验稳固后再考虑。

- 可选账号/云备份，不作为默认路径。
- 加密备份说明和恢复流程。
- 多设备同步前先做冲突策略。
- 共享手帐/好友贴贴/社区投稿只作为后续大版本评估，不进入近期主线。

## 第一阶段建议落实

推荐先做 v1.0.2 到 v1.1 的小闭环：

1. 今日一页入口。
2. 提示卡。
3. 心情标签。
4. 最近使用模板/素材。
5. JSON 备份导出。
6. 手动回归清单。

这一组能明显让手帐更接近日常使用，同时不会立刻引入云、社区、AI 审核风险。
