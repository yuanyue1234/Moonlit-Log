# 月亮手杖 v1.1.0 更新日志

日期：2026-06-17
分支：`dev`

## 本次定位

v1.1.0 是一次编辑体验整理：把页面管理、图片裁切、手绘工作台、贴纸预览和模板浏览往“更顺手做完一页手帐”靠近，同时继续守住贴纸唯一性和本地优先。

## 已完成

- 首页主标题从“收藏手帐”改为“月亮手杖”，副标题保持不变。
- 编辑模式底部恢复固定页面管理条：上一页、当前页/总页数、下一页、添加页、删除页固定排列。
- 预览模式隐藏底部页面管理条，避免编辑控件混入阅读状态。
- 删除页按钮在封面页/第一页或仅剩一页时保持占位但禁用，避免按钮位置跳动。
- 图片“更多”里的裁切改为可逆拖拽裁切：不再调用 `wx.cropImage` 生成新文件，而是保存 `cropMode/cropOffsetX/cropOffsetY` 到图片元素。
- 已裁切图片选中后会出现“调整裁切”按钮，可随时重新拖动位置；撤销/重做可回滚裁切参数。
- 删除封面图时，除了清空书本 `coverImage`，还会同步剔除封面页里的系统封面图片元素，避免旧封面重新出现或位置漂移。
- 手绘工作台底部移除“选择贴纸”，保留画笔颜色、画笔粗细、工具三项，画布下半区继续由真实 `.draw-board` 尺寸铺满。
- 手绘底部工具按钮改为与编辑页一致的暖纸色线条风，避免浅底白字不清楚。
- 贴纸库详情预览加入格纹预览底，白色或透明贴纸放大后也能看清边缘。
- 模板页改为更紧凑的三列浏览，一屏可看到更多模板；模板卡补充胶带、标题线、照片框、文字线等预览线索。
- 编辑器模板面板的模板卡也补充更真实的微型版式线索。
- 移除图片/矩形/元素更多菜单中的“复制样式”和“粘贴样式”，并清掉对应未使用逻辑。
- `scripts/verify-editor-ui.js` 更新为 49 项检查，覆盖新页面管理条、可逆裁切、手绘三工具、贴纸预览格纹和模板三列布局。
