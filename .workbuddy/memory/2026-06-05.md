# 2026-06-05

## 我的手帐小程序项目创建

完成了微信小程序"我的手帐"的完整 MVP 版本搭建。

### 项目结构
- 5 个页面：首页（手账本列表）、编辑器、贴纸库、AI提取、模板选择
- 3 个工具模块：storage.js（数据存储）、theme.js（主题管理）、template.js（模板系统）
- TabBar：手帐、贴纸、提取 三个标签

### 核心功能
1. **手账本管理**：创建/编辑/删除多本手账，8 种主题风格（奶油风、复古、韩系、日系、少女粉、海盐、咖啡、胶片）
2. **Canvas 编辑器**：支持贴纸拖拽/缩放/旋转、文字添加、背景切换、图层管理、撤销重做
3. **贴纸库**：分类管理（上传/AI抠图/收藏/系统）、收藏、删除
4. **AI 素材提取**：拍照/上传 → 模拟 AI 抠图 → 保存到贴纸库
5. **模板系统**：8 个预设模板（今日手帐、一周碎片、照片墙、小卡收藏等）
6. **导出功能**：Canvas 导出为图片、保存到相册

### 技术要点
- Canvas 2D 编辑器，支持触摸拖拽/双指缩放旋转
- 本地存储管理手账本/页面/贴纸数据
- 主题系统包含 8 套完整风格
- 使用 rpx 坐标系适配不同屏幕

### Bug 修复
1. **拖拽失效 Bug**: `touchToCanvas` 坐标转换错误 - 转为全局 rpx 而非 canvas 局部 rpx；`hitTest` 将元素转为像素但触摸是 rpx，坐标系不一致 → 统一使用 canvas-local rpx 坐标系
2. **图片不显示 Bug**: `img.complete` 同步检查永远 false，`onload` 回调在 save/restore 后无法绘制 → 实现全局 `imageCache` + 异步加载 + 加载完成后自动重绘
3. **Canvas 渲染问题**: 使用 `canvasNode.requestAnimationFrame` 确保渲染同步
4. **图片尺寸**: 添加图片时自动检测宽高比，按比例调整元素大小

### 新增功能
1. **AI 抠图 API**: 创建 `utils/ai.js`，支持 remove.bg API + 本地模拟 + 白边/阴影效果
2. **装饰元素系统**: 胶带(5色)、便签(4色)、边框(拍立得/撕纸/圆角/虚线)、日期戳、分割线(直线/波浪)、图案边框(星星/爱心)
3. **翻页动画**: 手账本卡片使用 CSS 3D perspective + rotateY 实现翻页效果
4. **新增装饰面板**: 编辑器底部工具栏新增「装饰」入口

## 第四轮：全面 bug 修复 + 稳定化

### remove.bg API 最终修复
- **根本发现**：`res.data` 返回的是 base64 字符串（typeof string），不是 JSON 对象
- 修复：`typeof res.data === 'string'` 时直接当 base64 用
- `response_type: 'base64'` + `responseType: 'text'`

### OffscreenCanvas 限制
- **关键发现**：`wx.createOffscreenCanvas` 的 `createImage()` 无法加载 `http://usr/` 虚拟路径
- `wx.getImageInfo` 也无法转换此路径
- **解决方案**：彻底放弃 OffscreenCanvas 做效果处理，ai.js 只负责去背景 + 标签
- 效果处理移至编辑器 Canvas（真实 canvas 节点）

### 数据保存修复
- 添加 `onHide` 生命周期自动保存
- `pushHistory` 每次操作后自动触发 `savePage`
- `savePage` 加 500ms 防抖

### 页面导航小圆点
