# 2026-06-06 手帐小程序优化

## 第一轮优化（16:29-17:00）

### UI 布局优化
1. **工具栏背景** - 改为透明背景 + 白色文字，选中时显示高亮
2. **预览按钮** - 移到工具栏最右边
3. **保存/导出** - 移入"更多"折叠菜单（三个点按钮）
4. **撤回/撤销** - 保持在工具栏不变

### 编辑器功能修复
5. **文字框字号** - 移除了字号选择器（保留拖拽缩放）
6. **页码跳转** - 改为原地切换页面，消除闪烁
7. **旋转手柄** - 修复触摸检测，现在可以正常拖拽旋转

9. **网格对齐** - 移动元素时显示蓝色虚线参考线，支持吸附对齐

### 新增功能
10. **手账本封面** - 支持从相册选择封面图片
11. **手账本标签** - 支持手动添加标签（最多5个）

### 贴纸库优化
12. **贴纸大小** - 上传时记录真实像素尺寸
13. **快速操作** - 点击贴纸后右下角显示收藏/添加到手账本/删除按钮
14. **排序功能** - 支持按最新/最早/名称排序

### 系统优化
15. **文件清理** - 每天自动清理未使用的 persist_*.png 文件，删除贴纸时同步清理文件

- **选中工具栏** - 背景改为灰白色 rgba(245, 245, 245, 0.95)，文字改为黑色 #333333
- **页码栏** - 背景改为灰白色，文字改为深色
- **整体颜色** - 统一协调，避免突兀对比

### 按钮重排
- **选中工具栏** - 移除"置顶"和"置底"按钮，移入"更多"菜单
- **删除按钮** - 放在"更多"按钮前面

### 动画简化
- **手账本点击** - 移除翻转动画，直接跳转
- **预览翻页** - 移除 3D 翻页效果，简化页面切换

### 贴纸预览优化
- **卡片样式** - 改为卡片式设计，圆角、阴影、内边距
- **关闭按钮** - 移到贴纸详情标题右侧
- **图片显示** - 修复手机预览时图片空白问题
- **编辑按钮** - 移除贴纸区域的编辑按钮

### 功能修复
- **撤回历史** - 切换页面时保持独立的撤回历史，不会失效

### 纸面材质真实效果
- **Canvas 叠加** - 在 Canvas 绘制时真实叠加材质效果
- **材质类型**：
  - 纸纹(grain) - 细微颗粒感
  - 画布(canvas) - 十字编织纹理
  - 牛皮纸(kraft) - 纤维纹理 + 噪点
  - 亚麻(linen) - 编织纹理
  - 水彩(watercolor) - 晕染效果
- **SVG 纹理** - 创建了 5 个 SVG 纹理文件在 assets/textures/ 目录
